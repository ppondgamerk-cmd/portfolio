# IT Support Internship Portfolio — POND

เว็บไซต์ Portfolio แบบหน้าเดียว (Single Page Website) ดีไซน์ระดับ Premium Dark Mode สำหรับนักศึกษาวิทยาการคอมพิวเตอร์ (ปอนด์) เพื่อใช้สมัครฝึกงานในตำแหน่ง **IT Support**

เว็บไซต์นี้ออกแบบมาให้มีความสวยงาม ทันสมัย โครงสร้างสะอาดตา รองรับการแสดงผลทุกหน้าจอ (Responsive) และมีเอฟเฟกต์แสงเรืองแสงสีม่วง/น้ำเงิน (Glow & Gradient Accent) คล้ายภาพตัวอย่างโครงสร้างต้นแบบ

---

## ✨ คุณสมบัติเด่นของเว็บไซต์ (Key Features)

1. **Premium Dark Theme**: ธีมมืดน้ำเงินดำ พร้อม Gradient แสงสีม่วงเรืองแสงรอบปุ่มและการ์ดเมื่อวางเมาส์ชี้ (Hover Effect)
2. **Dynamic Navigation Bar**:
   - ติดอยู่ด้านบนของหน้าเว็บตลอดเวลาเมื่อเลื่อนหน้า (Sticky Header)
   - แถบเมนูไฮไลต์ปุ่มตาม Section ที่กำลังเปิดอ่านโดยอัตโนมัติ (Scrollspy)
   - เมนูแฮมเบอร์เกอร์ที่ลื่นไหลบนสมาร์ตโฟนและแท็บเล็ต
3. **Interactive Project Detail Modals**: กดปุ่ม "ดูรายละเอียด" ของแต่ละการ์ดโปรเจกต์เพื่อเปิด Pop-up รายละเอียดพร้อมข้อมูลเครื่องมือที่ใช้ และ SVG การทำงานจำลองของระบบอย่างละเอียด
4. **Skills Bars Animation**: แถบวัดความสามารถทักษะคอมพิวเตอร์จะค่อย ๆ เลื่อนขึ้น (Animate) เมื่อหน้าจอกำลังเลื่อนผ่านส่วนทักษะนั้น ๆ
5. **Contact Form Validation**: ระบบตรวจสอบความถูกต้องก่อนส่งข้อมูล (เช่น ป้องกันช่องว่าง, ตรวจสอบรูปแบบอีเมล) และแสดงแจ้งเตือนการส่งข้อมูลสำเร็จแบบอัตโนมัติ
6. **Smooth Scroll & Back to Top**: การเลื่อนอย่างนุ่มนวลระหว่างแต่ละส่วน และปุ่มลอยที่มุมล่างขวาเพื่อกลับขึ้นด้านบนสุด
7. **Semantic HTML & Accessibility**: ใช้โครงสร้างแท็กมาตรฐาน เช่น `<header>, <nav>, <main>, <section>, <article>, <footer>` และติดแท็ก ARIA เพื่อให้โปรแกรมอ่านหน้าจออ่านง่ายขึ้น
8. **SEO Meta Tags**: พร้อมติดตั้ง Meta tags ที่จำเป็นสำหรับการค้นหาบน Google และแสดงข้อมูลรูปภาพตัวอย่างที่สวยงามเวลาแชร์ลิงก์ลงโซเชียลมีเดีย

## 🚀 ขั้นตอนการเปิดใช้งานเว็บไซต์ (Installation & Launch Guide)

คุณสามารถเปิดใช้งานเว็บไซต์นี้ได้อย่างง่ายดายผ่านขั้นตอนเหล่านี้:

### วิธีที่ 1: ดับเบิ้ลคลิกเพื่อเปิดโดยตรง (ไม่ต้องติดตั้งโปรแกรมเพิ่ม)
1. เข้าไปที่โฟลเดอร์โครงการ `portsfolio.1`
2. ดับเบิ้ลคลิกที่ไฟล์ `index.html`
3. เว็บไซต์จะเปิดผ่านเว็บเบราว์เซอร์หลัก (เช่น Google Chrome, MS Edge, Safari) บนเครื่องของคุณทันที

### วิธีที่ 2: เปิดผ่าน Local HTTP Server (แนะนำสำหรับงานพัฒนา)
หากต้องการทดสอบการทำงานให้เหมือนสภาพแวดล้อมเซิร์ฟเวอร์จริง:
* **หากใช้ VS Code**:
  1. ติดตั้งส่วนขยาย (Extension) ชื่อ **Live Server**
  2. เปิดโฟลเดอร์ `portsfolio.1` ใน VS Code
  3. คลิกขวาที่ไฟล์ `index.html` แล้วเลือก **Open with Live Server** (หรือกดปุ่ม Go Live ด้านล่างขวา)
* **หากใช้ Node.js**:
  1. เปิด Command Prompt / Terminal ในโฟลเดอร์โครงการ
  2. รันคำสั่งติดตั้งตัวรันเซิร์ฟเวอร์ชั่วคราว:
     ```bash
     npx http-server -p 8080
     ```
  3. เปิดเบราว์เซอร์ไปที่ลิงก์ `http://localhost:8080`

## ✍️ วิธีปรับแต่งและแก้ไขข้อมูลส่วนตัวภายหลัง

### 1. การเปลี่ยนรูปโปรไฟล์และรูปภาพโปรเจกต์
* นำไฟล์รูปภาพที่ต้องการมาตัดขอบตามสัดส่วนที่เหมาะสม
* บันทึกไฟล์รูปภาพเป็นฟอร์แมต `.png` หรือ `.jpg` แล้วตั้งชื่อให้ตรงกับรูปเดิม จากนั้นนำไปวางแทนที่ในโฟลเดอร์ `assets/images/`
  * เช่น แทนที่รูปโปรไฟล์ด้วยชื่อ `profile.png`
* *หมายเหตุ: หากไม่มีรูปภาพในโฟลเดอร์ เว็บไซต์จะแสดงกราฟิกจำลองเวกเตอร์ SVG อันสวยงามแทนโดยอัตโนมัติเพื่อไม่ให้เกิดข้อผิดพลาดรูปภาพเสีย*

### 2. การเปลี่ยนไฟล์ดาวน์โหลด Resume PDF
* บันทึกไฟล์เรซูเมของคุณให้อยู่ในฟอร์แมต PDF
* ตั้งชื่อไฟล์ว่า `resume.pdf`
* นำไปวางแทนที่ไฟล์เดิมในโฟลเดอร์ `assets/`

### 3. การเปลี่ยนข้อมูลข้อความ (เช่น ช่องทางติดต่อ และเกรดเฉลี่ย)
* เปิดไฟล์ `index.html` ในโปรแกรมแก้ไขโค้ด (เช่น VS Code, Notepad++)
* มองหาแท็กที่มีข้อมูลที่ต้องการเปลี่ยน เช่น:
  - แก้ไขอีเมล: ค้นหาคำว่า `pond.itsupport@email.com` แล้วเปลี่ยนเป็นอีเมลจริงของคุณ
  - แก้ไขเบอร์โทร: ค้นหาคำว่า `099-123-4567` แล้วใส่เบอร์จริงของคุณ
  - แก้ไขข้อมูลการศึกษา: ไปที่ส่วน `<section id="experience">` แล้วแก้ไขชื่อมหาวิทยาลัยและรายละเอียดการเรียน
